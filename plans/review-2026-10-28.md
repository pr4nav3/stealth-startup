# Review before shipping (2026-10-28, Windows, read-only)

Everything on `feat/remove-now-line` at `5518cd6` plus the uncommitted History-tab
and animation edits, read file by file, every screen rendered in the mock, 210 tests
and the build passing. Nothing here was changed; this is the list.

## The thought process, as read from the commits

Three weeks of commits tell one story: a focus buddy that feels like a person, not a
dashboard. Every pass since the V2 rules took something away or made it plainer: one
distractions list, one vocabulary, a card that says what happened in a sentence, a voice
that speaks the moment the card appears, a Home that fits its window exactly. The
Pomodoro and review work of the last three days follows the same line: breaks that judge
nothing, a tomato per round, one question after a session instead of a classify queue,
Trends that start at the first session. The thing being polished is the feeling of being
watched kindly, and the code mostly delivers it.

## What is not up to snuff, ranked

### Would embarrass a release

1. **The report and the "Any distractions?" review are lost if anything is open when a
   session ends.** `main.ts:1006` marks the new session seen before checking
   `editorIsOpen()`. A timer that runs out while a line generates, a voice popup is open,
   or Quit is asking leaves the user on that page with the "Session done" card, no report,
   and the review never offered again.
2. **Two paths open the same report.** `stop` opens it from the command result and
   `session-end` opens it again from the event; both fetch review candidates and can
   render over each other.
3. **Nothing ships.** No GitHub Release holds the app or the `voice-runtime` manifest the
   binary compiles in, so every installed copy's voice download fails and the Mac
   one-liner has nothing to fetch. The one-liner reads `main`, which is two days behind
   this branch. There is no Windows installer; the Windows webcam worker has never been
   frozen; `bundle.active` is false in the day-to-day config.
4. **The sleep-aware clock has never run on Windows.** Lost time, the timer and a break's
   end all read `Instant`; if it does not advance across Modern Standby, a closed lid makes
   the session run long by the sleep and the break with it. One lid-close test settles it.
   Nothing on this branch has run live on Windows since 2026-10-18.
5. **A sleep across a round boundary is not capped at the round.** Lost time is capped at
   the session's end only; the overrun lands in the old round and the next round is
   shortened by it.
6. ~~The live bar and the timeline separators are black in dark mode.~~ Checked and
   withdrawn: the live bar and the report timeline sit on cards whose colours are fixed in
   both themes, so their fixed ink is right. In its place: the status window's break buttons
   wrapped once renamed; they now stack on a break.

Items 1, 2, 4 (the command side), 5 and the wording were fixed on `fix/release-six` the same
day; the Windows lid-close test (item 4) still needs a person.

### Rough edges a careful user notices

7. **"Ask me later" never asks later.** It drops the review; the same apps only come back
   if they show up in another session. Say "Skip".
8. **A typed rename is lost on Save** in the review unless Enter was pressed first.
9. **The same action has three names.** Main window "End session" vs status window
   "Stop"; "Start round 3" vs "Next round"; "Start break" on a card for a break that has
   already started.
10. **Jargon survived the pass**: "Delete clips, keep the recording", eyebrows "Voice
    worker" and "Voice model", a "Runtime" row, toasts "Model files deleted" and "Voice
    files deleted", "Custom Local N" as a default name, and a toast pointing at a "Lines
    for" dropdown that no longer exists.
11. **Dates in two locales**: the report line forces en-GB and en-US while everything else
    follows the system.
12. **The empty status window** reads "One clear start. Your distractions and voice are set
    when you start." Placeholder copy.
13. **Dialogs do not take focus**: the review, the confirms, the session-over card and the
    delete-voice dialog open with focus left behind them and do not trap Tab.
14. **Commands read the clock before taking the lock** (`lib.rs:85,112,134,…`), so a
    pause or stop can land one second behind the last tick: reports a second shorter than
    their spans. `with_sessions` also drops tray actions and webcam frames after any panic
    instead of recovering the lock like `lock_sessions` does.
15. **History off makes every session after the first silent**: with session id 0, the
    nudge counter never passes the previous session's count, so cards show but no voice.

### Under the surface

16. **The CI layout check is partly fake.** Three voice-page states click buttons that no
    longer exist and measure the bare page; the review dialog, Trends by month, the
    personality menu, the session-over card and the quit confirm have no state at all.
17. **Dead code from four rewrites** is still in: a dozen unreferenced functions
    (`readyClipCount`, `voicePhraseInputs`, `phraseKind`, `canGenerateClip`, …), the webcam
    `strict`/`reaction` branches that can never run, `evidence` and `events` fields nothing
    renders, `away_seconds` always 0, `WEBCAM_SETTING_KEYS` seeding keys nothing reads,
    `'paused'` filters after v14, and some thirty CSS classes with no element.
18. **Tests missed the new seams**: the tiling fuzz never starts a Pomodoro; no test for
    early resume from a break, manual pause inside a round, stop during a break, recovery
    of a session in a break, a round ending on the phone, `review_candidates`, or the v14
    overlap case (a span that began inside a pause keeps its full length).
19. **Docs are two days behind**: `known-issues.md` still says a session is never rewritten
    (the review now flips spans), says v13 (it is v14), says "Not today"; `STATUS.md` lists
    the voice grouping as not built; `mac-handoff.md` still describes the Now line; the
    example runtime manifest points at the August zip that cannot start; the landing page
    says the window title tells sites apart (it is the address bar) and mentions a pin and
    a Snooze the app does not have.
20. **Repo**: 12 MB of starter WAVs is fine, but `voice-samples/` and `voice_bakeoff/`
    are research leftovers at the root, 19 merged branches are still on origin and
    locally, and the repo is public under a placeholder name.

## What is good and should not be touched

The span-tiling invariant and its fuzz test; the one-tone-per-voice rule; the Accessibility
address read on the Mac; the schema migrations (v12 to v14) with their tests; the Home
layout that fits exactly; the Trends period maths (DST-safe, month roll-over tested); the
mock harness. The product idea is intact and the hard parts work.
